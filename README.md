# 西桟橋 Starlink Viewer

竹富島・西桟橋からスターリンク衛星トレインが見えるタイミングを案内するWebアプリ。

## コンセプト

> 衛星観測ツールではなく、西桟橋に立った人が空を見上げる"きっかけ"をつくる装置。
> 場所・時間・方角だけを、静かに提示する。

## 機能

- **観測しやすさインデックス（0〜100）** を最上位に常時表示
  - どんな条件でも「今夜の推奨時間帯 / 方角 / 一言アドバイス」を必ず提示
  - 衛星条件・薄明・月・雲量を統合した総合スコア
  - **観測時刻5分前に自動で "about-to-start" 強調モード**へ遷移
- **📅 カレンダーに追加**ボタンで .ics ダウンロード（今夜の候補+次回新月期）
- **🧭 方角ガイド**（スマホのコンパスと連動、推奨方向を矢印で指示。HTTPS必須）
- 今夜スターリンクのトレインが見える可能性を判定する
- 見える場合: 時刻 / 方角 / カウントダウン / 流れる方向を表示する
- **複数候補**: 今夜複数のトレインがあればセカンダリも提示する
- **可視スコア（0〜100）**: 衛星数・高度・月齢・薄明適性・雲量を統合した見やすさ指標
- 見えない場合: **理由を診断**（月明かり・衛星軌道・雲・薄明ズレ）、次の候補日 または 新月期を提示する
- 今夜の月齢・月相・潮の種類を折りたたみで提示する（トグル）
- 日の出 / 日の入り / 月の出 / 月の入り / 薄明時刻を表示する
- 石垣港の満潮・干潮時刻と潮位を表示する（気象庁データ）
- 竹富島の雲量・視程・気温を表示する（Open-Meteo）
- 時刻に連動して背景色が変化する（夕焼け → 薄明 → 夜）

## 予測精度

- **Celestrak全量取得**（約10,000機、成功時）またはフォールバックで200機
- **軌道高度フィルタ**: 200〜600km の運用軌道にある衛星のみを候補化
- **トレインクラスタ検出**: 5分以内・方位角30°以内に3機以上で可視トレインと判定
- **観測窓**: 18:00 〜 翌02:00 JST の8時間スキャン

## 技術スタック

| レイヤ | 採用 |
|--------|------|
| Webフレームワーク | FastAPI + Jinja2 |
| 衛星軌道計算 | Skyfield |
| 日月計算（日の出・月の出・薄明） | Skyfield almanac |
| 潮汐データ | 気象庁（石垣港 IS.txt、年次取得） |
| 天候（雲量・視程・気温） | Open-Meteo（APIキー不要、15分キャッシュ） |
| TLEデータ | tle.ivanstanojevic.me / Celestrak（多重フォールバック） |
| キャッシュ | メモリ（2時間）+ ファイル（24時間）|
| フロント | バニラJS（依存ゼロ） |
| PWA | manifest.json + Service Worker |

## 観測パラメータ

| 項目 | 値 |
|------|-----|
| 緯度経度 | 24.3237°N, 124.0893°E（西桟橋） |
| 対象時間 | 18:00〜21:00 JST |
| 最低高度 | 30°（今夜）/ 20°（翌日以降の予測） |
| 薄明条件 | 太陽高度 -18°〜-6° |
| トレイン判定 | 5分以内・方位角30°以内に3機以上 |

## ローカル実行

```bash
cd starlink_nishi
pip install -r requirements.txt
uvicorn main:app --reload
```

ブラウザで http://127.0.0.1:8000 を開く。

## デプロイ（Render）

1. GitHubリポジトリをRenderに接続する
2. `render.yaml` が自動検出される
3. デプロイ完了

## ファイル構成

```
starlink_nishi/
├── main.py              # FastAPIアプリ本体（計算・API）
├── tide.py              # 気象庁潮汐データのフェッチ・パース
├── weather.py           # Open-Meteo雲量・視程・気温のフェッチ
├── templates/
│   └── index.html       # UI（時刻連動背景・カウントダウン・日月/潮汐/天候表示）
├── static/
│   └── manifest.json    # PWAマニフェスト
├── de421.bsp            # 惑星暦（太陽・月の位置計算用）
├── tle_cache.json       # TLEファイルキャッシュ（自動生成）
├── tide_cache_YYYY.txt  # 潮汐年次データキャッシュ（自動生成）
├── test_mock.py         # 単体テスト（モック）
├── test_integration.py  # 統合テスト（ネットワーク必要）
├── requirements.txt
└── render.yaml
```

## テスト

```bash
# ネットワーク不要のロジックテスト
py test_mock.py

# TLE取得を含む統合テスト
py test_integration.py
```
